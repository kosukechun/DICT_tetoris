# 操作説明

名前だけで登録できます。同じブラウザーのCookieにより、最大365日間プロフィールを識別します。IDとパスワードの入力はありません。名前の変更でも履歴は残ります。別端末やCookie削除後に、名前だけで履歴を復元する機能はありません。

操作、消去・連鎖、お邪魔の相殺と落下、シールド、CPU、オンライン対戦は **[READMEの操作とルール](../README.md#操作とルール)** を参照してください。ゲーム画面内の「遊び方」からも確認できます。

灰色のお邪魔は1個単位です。相手への攻撃より自分への予告の相殺を優先し、残りだけ相手へ送ります。消去できなかった着地で、予告から1.2秒経過したお邪魔が1回最大6個、上から1個ずつ落下します。

切断や途中終了は敗北です。10分経過時はスコアで判定します。終了後に履歴を確認でき、JSON形式でダウンロードできます。
