# 操作説明

名前だけで登録できます。同じブラウザーのCookieにより、最大365日間プロフィールを識別します。IDとパスワードの入力はありません。名前の変更でも履歴は残ります。別端末やCookie削除後に、名前だけで履歴を復元する機能はありません。

操作、消去・連鎖、お邪魔の相殺と落下、シールド、CPU、オンライン対戦は **[READMEの操作とルール](../README.md#操作とルール)** を参照してください。ゲーム画面内の「遊び方」からも確認できます。

灰色のお邪魔は1個単位です。攻撃と予告スタックは最大6個で、相手への攻撃より自分への予告の相殺を優先し、残りだけ相手へ送ります。消去できなかった着地では予告から1.2秒経過したお邪魔が、上から約0.2秒間隔で1個ずつ落下します。

切断や途中終了は敗北です。オンライン戦・CPU戦とも5分経過時は盤面に固定されたブロックが少ない方の勝利で、同数なら引き分けです。自動落下は時間経過で加速せず、0.65秒間隔を維持します。終了後に履歴を確認でき、JSON形式でダウンロードできます。

ホームの「CHEAT MODE」はパスワード `tomo` でONになります。ONにしたプレーヤーは5秒ごとに相手へお邪魔を2個送ります。オンライン戦とCPU戦の両方で有効です。もう一度押すとOFFになります。「ADMIN CHEAT」のパスワードは `chun` で、追加で自分の盤面から5秒ごとに最大3個を消します。

「トーナメント」から3〜8人の大会部屋を作れます。他の参加者は6文字の部屋コードを入力し、全員が集まったら主催者が開始します。必要なシードは自動で抽選します。勝者は部屋に戻って次の試合の準備完了を押してください。引き分けは再試合、退出・切断は不戦敗です。

名前を `chun` にすると画面下に「管理者」が表示され、CPU戦・通常のオンライン戦・大会すべての禁止時間帯と即時停止・再開を操作できます。別の名前に変えると権限を失います。時間帯と停止状態は保存され、再起動後も維持されます。詳しくは[READMEの管理者機能](../README.md#管理者チートゲーム禁止時間帯)を参照してください。
